# CFO presentation outline — six slides

Designed for the case-study's five-minute CFO demo; each slide uses the same rebuilt warehouse metrics.

1. **Business question and scope** — Why do six months of overtime exports tell different stories? Identify synthetic-data context and April–September window.
2. **Reproducible pipeline and controls** — 12 raw files → staging → attendance → constrained SQLite star schema → 10 SQL questions; summarize reconciliation and DQ coverage.
3. **Attendance reconstruction** — Show employee-day totals by status and explain night shifts, two-minute punch deduplication, roster fallback and device correction.
4. **Overtime reconciliation** — Compare punch-computed, approved and paid hours; support the gap with monthly/department CSV and state clearly that this is a review signal.
5. **Top three CFO findings** — Overtime gap, Missing Punch queue and payroll after separation, each with query evidence and action.
6. **Decision / next actions** — Employee + shift-date OT reconciliation, attendance/device investigation, payroll-policy review and limitations.

The matching presentation is generated by `build_deck.py`; it is limited to six slides and refreshed by `run_pipeline.py`.
